# A3 — Android player per mode: Nghe hides transcript, Phản xạ/Nói countdown, hidden answers
Status: todo · Suggested agent: codex/gpt-5.6-sol (medium) · Session: new · Size: M · Device check: user
Wave: 5 · Owns: `kmp/android/.../ui/player/` (TranscriptPanel, NowPlaying, PlayerViewModel/UiState), `playback/` (pause-in-gap only), a pure helper in `kmp/shared/.../modes/` (gap state), tests + goldens · Depends on: A1, A2 · Checkpoint after: no (A4 continues; PM + user at wave end)

## Goal
Each mode plays differently in the existing player:
- **Nghe:** transcript hidden by default ("Nghe thuần"); a "Hiện câu" button reveals only the current cue's text until the next cue starts. Audio unaffected.
- **Phản xạ:** in every `answer` gap (timeline `gaps`, A1) a countdown ring shows the remaining gap time. Transcript never shows cues that haven't started yet (answers stay hidden until spoken). A "Cần thêm thời gian" button pauses playback inside the gap; play resumes at the same point.
- **Nói:** the same countdown ring in every `repeat` gap (time to say the phrase back) and the same pause button. Recording + pronunciation scoring is a later wave.
- **Hiểu:** unchanged.
