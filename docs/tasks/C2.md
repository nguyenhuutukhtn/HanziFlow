# C2 — Character card UI (Android)
Status: todo · Suggested agent: codex/gpt-5.6-luna (low) · Session: new · Size: M/L · Device check: user

## Goal
The learner can see, for any Hanzi in a lesson, a card with its Hán-Việt reading, pinyin,
Vietnamese meaning, the components it is built from and the lesson words that use it —
reached by long-pressing a token (lookup sheet → character row) or from a "Chữ của bài"
list opened from Now Playing. Read-only UI over the `characters.json` already in every
lesson package (lesson_001 v7: 83 characters + 94 prerequisite components). No progress
tracking, no SRS, no stroke animation.

## Design decisions (user, 2026-10-21 — don't reopen)
- Entry points, all three: (a) lookup sheet gets a row of per-character chips for the word's
  Hanzi; tapping one opens the character card; (b) a **"Chữ của bài"** screen/route opened from
  Now Playing; (c) components inside a card are tappable and open that component's card,
  stacked in place with a back affordance.
- **No "Xem nét" (stroke animation)** anywhere — the stroke base package does not exist yet.
  `stroke_available` is ignored in this task; no disabled button.
- **`phonetic_family` is shown**, at most 4 characters, view-only (not tappable), under a
  Vietnamese label making clear it is reference only ("Cùng bộ phận biểu âm · chỉ để tham khảo").
- **No progress / "đã biết chữ này" state** — that belongs to G2c (Review tab + SRS).

## Acceptance
- `characters.json` of lesson_001 v7 parses; the index answers exactly:
  - `我` → pinyin `wǒ`, Hán-Việt `ngã`, vi `tôi, mình`, hsk 1, lessonWords contains `我们` and `我`.
  - `components_prereq` holds 94 entries; `扌` → nameVi `thủ đứng`, role `component`; `戈` → `qua`.
  - `componentsOf("我")` = `[扌, 戈]` (the ⿰ is dropped, both resolved from `components_prereq`).
  - `charactersOf("我们")` returns 2 entries, in order `我`, `们`; `们` has a non-empty `phoneticFamily`.
  - At least 5 sampled characters spread across the file (first, ~20th, ~40th, ~60th, last)
    have non-empty `han_viet` and `vi_meaning` — print them in Verify.
- A catalog entry **without** `files.characters` still deserializes (`characters == null`).
- Long-press a token in Now Playing → lookup sheet shows a chip per Hanzi of the word; tapping
  one opens the card with the fields of §3; tapping a component chip opens that component's card
  and back returns to the first one.
- "Chữ của bài" from Now Playing lists 83 characters + 94 components for lesson_001 v7.
- A lesson with no character data shows no chips, no "Chữ của bài" entry, and no crash.
- No "Xem nét" button anywhere; `phonetic_family` renders at most 4 characters, not tappable.
- `bash scripts/check.sh` passes (pytest, shared allTests, android unit tests incl. Konsist
  layering, codemap, file-size audit); no new ⚠ file over 300 lines in `docs/CODEMAP.md`.
