## Goal
Everything X3's UI needs, tested on the JVM: send a line to an OpenAI-compatible chat API, keep the
whole thread (explanation + follow-ups) in Room keyed by lesson + line id, and return the saved
thread on reopen without a network call.

## Do
1. **Config:** `local.properties` keys `llm.base_url`, `llm.model`, `llm.api_key` → BuildConfig `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`, all **optional** (default `""`, no `error(...)`, unlike `supabase.url`). `AiConfig.isConfigured` = all three non-blank. Never log the key.
2. **Prompt:** copy `prompts/explain_line.md` into the APK assets at build time (Gradle `Copy`/`sourceSets` assets dir pointing at repo `prompts/` — one source of truth, no duplicate file in git). `ExplainPrompt.render(line, before, after)` fills the X1 placeholders; context = up to 2 Chinese lines before/after in the same track.
3. **Client:** `ChatClient` interface `suspend fun complete(messages: List<ChatMessage>): String`; `OpenAiCompatibleClient` on OkHttp (already a dependency) + kotlinx-serialization: POST `<base_url>chat/completions` (`base_url` ends with `/`; add it if missing), `Authorization: Bearer <key>`, body `{model, messages}`, read `choices[0].message.content`. Timeout 60 s. Errors → a typed failure with HTTP code + short message, key redacted.
4. **Store:** Room entity `ExplainThreadEntity(lessonId, lineId, hanzi, lessonVersion, messagesJson, updatedAt)`, primary key (lessonId, lineId); `messagesJson` = list of `{role, content, createdAtMs}` (system message not stored — rebuilt from the prompt file; the rendered first user message IS stored so follow-ups replay exactly). DB version 3 + `MIGRATION_2_3` (CREATE TABLE only; existing tables untouched).
5. **Repository** `ExplainRepository`: `thread(lessonId, lineId): Flow<ExplainThread?>`; `explain(line, context)` — if a thread exists for (lessonId, lineId) **with the same hanzi**, return it, no network; else call, save `[user, assistant]`; `ask(lessonId, lineId, question)` — append user msg, call with system + full history, append answer, save; on failure keep the user message marked failed (so it can be retried) and keep everything else. `ExplainThread.isStale` = saved hanzi ≠ current line hanzi (UI offers "Giải thích lại", which replaces the thread).
6. **ViewModel** `ExplainViewModel` (Hilt, like the existing ones): state = `NotConfigured | Loading | Ready(thread, sending: Boolean, error: String?)`; `open(line, context)`, `send(question)`, `retry()`, `reexplain()`.
