# T4 — Make screenshot tests actually guard the UI
Status: todo · Suggested agent: Codex or a fresh Claude Code window (Gradle + shell, no UI design) · Size: S · Device check: none · After L2-fix is committed

## Goal
Today no Roborazzi golden is committed (`kmp/android/src/test/screenshots/` doesn't exist; output goes to `build/outputs/roborazzi`, which `check.sh` runs can wipe) and `scripts/check.sh` never runs `verifyRoborazziDebug`. So every UI task spends tokens writing screenshot tests that guard nothing, and the user can't find the images to approve. Fix the loop: record → user looks → approve → committed goldens → `check` compares.

## Read only
- `.claude/skills/android-ui-testing/SKILL.md`, `justfile`, `scripts/check.sh`, the `roborazzi { }` block in `kmp/android/build.gradle.kts`.

## Do
1. Goldens live in `kmp/android/src/test/screenshots/` (committed); compare/diff images stay in the build dir.
2. `just screens` (wrapper `scripts/screens.sh`): record into a review dir (`kmp/build/screens-review/`), print ≤ 20 lines: each new or changed image path vs. the committed golden, then `open` that folder on macOS. No AI needed to look.
3. `just approve-screens [name…]`: copy the reviewed images (all, or the named ones) into the goldens dir and print what changed.
4. `scripts/check.sh`: add a `screens` step running `verifyRoborazziDebug` when the goldens dir is non-empty (skip with `ok screens (no goldens)` otherwise); on failure print the diff image paths only.
5. Update the skill's Commands section and `docs/workflow.md` principle 4 (one line each).

## Acceptance
- `just screens` lists the L2 images (`now_playing_section_loop`, `now_playing_chinese_only`, `mini_player_section_loop`, …) and opens the folder; after `just approve-screens`, `scripts/check.sh` shows `ok screens`; a deliberately changed color makes it `FAIL screens` with the diff path.

## Verify
`scripts/check.sh` (green, then the deliberate failure, then revert).

## Out of scope
Changing any screen or test content; device checks.

Then: update STATUS.md + a token_log.md row, report with the AGENTS.md template, do not commit.
