# C0 — Bộ thủ Vietnamese names (data/radicals_vi.json)
Status: todo · Suggested agent: fresh Claude Code (WebSearch/WebFetch for Kangxi list) · Size: S · Device check: user (none)

## Goal
Generate `data/radicals_vi.json`: Vietnamese names for ~214 Kangxi radicals + ~30 simplified-only components (氵讠扌钅饣纟 etc.). This file is consumed by C1 to populate `components_prereq[].name_vi` in `characters.json`.

## Read only
- `docs/architecture/characters.md` — schema for `components_prereq`, list of simplified-only components to cover.
- Nothing else in the repo.

## Do
1. Fetch the 214 Kangxi radicals (Unicode chart or Wikipedia table): codepoint, character, stroke count, English name.
2. Add the ~30 simplified-only components that appear in MMAH decompositions but are not Kangxi radicals: 氵讠扌钅饣纟糹阝(left)阝(right)…
3. For each entry, generate a Vietnamese name following conventions:
   - Traditional 1-char bộ name where known (e.g. 木→ "mộc").
   - Descriptive positional name where conventional (e.g. 氵→ "ba chấm thủy", 讠→ "ngôn đứng", 扌→ "thủ đứng", 钅→ "kim đứng").
   - Fallback: transliterate the Hán-Việt reading (Unihan kVietnamese via `kTraditionalVariant` bridge if needed).
4. Write `data/radicals_vi.json`:
```json
[
  { "char": "氵", "kangxi_index": null, "simplified_only": true, "name_en": "water (3-dot)", "name_vi": "ba chấm thủy" },
  { "char": "木", "kangxi_index": 75, "simplified_only": false, "name_en": "tree", "name_vi": "mộc" }
]
```
5. Update STATUS.md (Done section, one line) + token_log.md row. Do not commit.

## Acceptance
- File exists at `data/radicals_vi.json`, valid JSON array.
- Every entry has `char`, `kangxi_index` (null if simplified-only), `simplified_only`, `name_en`, `name_vi` (no nulls — if unknown, use Hán-Việt reading).
- Covers all 214 Kangxi radicals + the simplified-only components: 氵讠扌钅饣纟糹阝(left)阝(right)忄礻衤月(flesh)廾癶𠂉 (at minimum).
- `name_vi` for 氵讠扌 matches the examples above (PM spot-check).
