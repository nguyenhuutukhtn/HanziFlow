## Goal
Long-press any Chinese transcript line → small menu "Giải thích" / "Sao chép" → bottom sheet that
shows the AI explanation rendered as Markdown and a chat box for follow-ups; reopening a line shows
the saved thread instantly. Audio keeps playing throughout.
