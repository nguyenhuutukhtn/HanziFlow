# A4 — Android: "Lặp mỗi câu ×2" for Nói / Phản xạ (service-owned, works screen-off)

Wave: 5 · Owns: `kmp/android/.../playback/` (LoopController, LoopState, PlaybackService/Coordinator, PlaybackExtras/Contract), a pure helper in `kmp/shared/.../transcript/` or `modes/`, `ui/player/` (one chip), tests + goldens · Depends on: A1, A3 · Checkpoint after: yes (PM, then user on device — wave end)

## Goal
To repeat phrase by phrase without touching the phone: in Nói and Phản xạ a chip "Lặp ×2" makes every cue play twice before moving on. One unit = the cue **plus its following gap** (so the learner gets the answer/repeat time again). Off by default; remembered per mode. Existing speed control and "Nghe lại câu" stay as they are.

## Read only
- `playback/LoopController.kt` (single active loop; `onPositionReached` returns a seek target), `LoopState.kt`, how the service ticks it (`PlaybackService`/`PlaybackCoordinator`)
- Shared `Timeline.gaps` (A1), `CueNavigation.kt`
- `ui/player/NowPlayingScreen.kt` + `PlayerUiState.kt` (where the loop chip lives), skill `.claude/skills/android-ui-testing/SKILL.md`

## Do
Write the tests first.
1. Shared pure function `repeatUnits(timeline): List<RepeatUnit(startMs, endMs, lineId)>`: one unit per cue, `endMs` = next cue's `start_ms` (or `duration_ms` for the last), so gaps are included.
2. A new loop kind in `LoopController` ("repeat each ×2"): reaching a unit's end for the first time seeks back to its start; the second time it continues. It lives in the service like the line loop (works with the screen off and from the lock screen). A manual line/section loop replaces it, and clearing that loop restores it if the chip is still on. Seeking, next/previous (headset) reset the pass count to the new unit.
3. Chip "Lặp ×2" shown only for `phan_xa` and `noi` of a `modes_v1` lesson. State persisted per (lesson, track) in the A2 repository.
4. The A3 countdown keeps working in the repeated gap (it is position-driven).

## Acceptance
- `repeatUnits` on real `timeline_noi.json`: first unit `lineId == "noi_s1"`, `endMs ==` the second cue's `start_ms`; unit count == cue count; last unit ends at `duration_ms`.
- `LoopController` test (fake ticks): with repeat on, ticks through unit 2's end → returns unit 2's start once, then lets the next unit play; a seek into unit 5 → unit 5 plays twice; a line loop set then cleared → repeat resumes.
- ViewModel/UI test: chip visible for `noi`/`phan_xa`, absent for `hieu`/`nghe` and lesson 1; toggling persists across a new ViewModel.
- Lesson 1 loop/playback tests unchanged.
- Golden: Nói player with the chip on (light + dark).
