# S1 — Stroke-order base pack: pipeline build/upload + shared model + Android download
Status: todo · Suggested agent: Codex IDE extension, gpt-5.6-luna (low) · Session: new · Size: M · Device check: agent (one logcat/file check, see Verify)

## Why
"Xem nét" (stroke-order animation) was decided in [architecture/characters.md](../architecture/characters.md)
but deferred out of C2 because the data wasn't packaged for the app yet. The raw data is
already fetched: `data/hanzi_writer/<char>.json` (9575 files, from R1's
`scripts/fetch_character_data.sh`), each `{"strokes": [...SVG path "d" strings...],
"medians": [...point arrays...], "radStrokes": [...]}`. Checked for this brief: only `M L Q C Z`
path commands appear (no arcs) — confirmed by sampling 40 files. `characters.json` already
carries `stroke_available: bool` per character (computed in
`src/mandarin_course/characters/resolve.py:119` from `StrokeLoader`), it's just never shipped
to the app. Shipping the **full** 9575-char set (~77MB) is wasteful; lesson_001's 177
characters+components need only ~316KB. This task ships the base pack as a **separate,
one-time-download artifact** (not per-lesson, not bundled in the APK), sized to only the
characters actually used across published lessons, versioned/updated like U1's catalog.

## Do
1. **Pipeline — build the pack:** new command `mandarin-course build-stroke-pack` (own module
   under `src/mandarin_course/characters/`, keep under 300 lines) that:
   - Scans every `publish/lessons/*/v*/characters.json` for the **currently catalogued**
     version of each lesson (read `publish/catalog.json`, not every version dir) and unions
     `characters[].char` + `components_prereq[].char` across all of them.
   - For each char with `stroke_available: true`, copies its `data/hanzi_writer/<char>.json`
     (strokes + medians only, drop `radStrokes` — unused) into one combined
     `publish/stroke_pack/strokes.json` map (`{char: {strokes, medians}}`), plus a manifest
     entry in `catalog.json` (new top-level key, e.g. `"stroke_pack": {"version": N, "files":
     {"strokes.json": {"sha256": "...", "bytes": N}}}`) following the same digest-compare
     pattern `publish.py` uses for lesson versions: unchanged → report `unchanged vN`, changed
     → write `vN+1`, keep the previous version's file alongside until the next cycle (same
     "verify before prune" pattern as U1).
   - No TTS, no network calls beyond reading already-fetched local files — never calls ElevenLabs.
2. **Pipeline — upload:** extend `upload.py`/`upload_storage.py` to also sync
   `publish/stroke_pack/vN/strokes.json` to a new bucket prefix `stroke-pack/vN/strokes.json`
   (same immutable/versioned cache-control as lesson files), verify from the public endpoint
   like lesson files, and prune only `stroke-pack/vN` dirs older than current+previous — do
   **not** touch the lesson-package prune logic.
3. **`kmp/shared`:** add to `catalog.json`'s parsed model a `strokePack: StrokePackRef? =
   null` (version + a `Clip`-like file ref, following `PackageFiles`'s optional-field pattern
   so old catalogs still parse) and a new `commonMain/.../shared/characters/StrokeData.kt`
   (`@Serializable StrokeEntry(strokes: List<String>, medians: List<List<List<Int>>>)`, a
   `StrokePack` wrapping the `Map<String, StrokeEntry>`, parsed with `CourseJson`). Keep under
   300 lines; this is parsing only, no rendering (that's S2).
4. **Android — download + cache:** add a `suspend fun strokePackFile(): File?` to
   `CourseRepository`/`CourseRepositoryImpl` (+ `FakeCourseRepository`) that downloads
   `strokes.json` once per catalog version to local storage (same hash-verified pattern as
   `LessonDownloadWorker`, but catalog-scoped, not lesson-scoped — one file for the whole app,
   not one per lesson). Re-download only when the catalog's `strokePack.version` changes.
   Do **not** wire any UI yet — S2 owns the renderer and the "Xem nét" entry point.
5. Update `docs/STATUS.md` (S1 done) and add a `docs/token_log.md` row. Do not commit.

## Acceptance
- `mandarin-course build-stroke-pack` on the current `publish/` produces `stroke_pack/v1/strokes.json`
  containing exactly the union of lesson_001 v7's 177 chars that have `stroke_available: true`
  (print the count and 3 sample chars' key presence in Verify); re-running with no catalog
  change reports `unchanged v1`.
- A catalog **without** `stroke_pack` still deserializes in `kmp/shared` (`strokePack == null`).
- `upload` (dry-run) lists `stroke-pack/v1/strokes.json` as a planned upload alongside lesson files.
- `CourseRepository.strokePackFile()` downloads the file once, verifies its hash, and returns
  the cached path on a second call without re-downloading (assert via a log line or call count
  in the test, not a real network call).
- `bash scripts/check.sh` passes; no new file over 300 lines in `docs/CODEMAP.md`.
