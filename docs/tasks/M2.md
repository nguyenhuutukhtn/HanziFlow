## Do
1. `content/lesson_002/meta.json` (exact values):
   ```json
   {"lesson_id": "lesson_002", "title": "你在哪儿？", "level": "absolute_beginner",
    "communicative_goals": ["Hỏi và nói mình đang ở đâu: tòa nào, tầng nào, ở cửa"],
    "new_patterns": ["在 + nơi chốn", "在哪儿？", "V 不去 / V 不见"],
    "voice_genders": {"coach_zh": "female"}}
   ```
2. Parser (`story/modes.py`): sections `## Hiểu|Nghe|Phản xạ|Nói` → modes `hieu|nghe|phan_xa|noi`; inside each section's ``` block, one row per line `ref | speaker | 中文 | pinyin | Tiếng Việt`; other sections ignored. Errors (wrong cell count, unknown speaker, gap as first row, `coach_vi` outside Hiểu) print `09_modes.md:<line>: <reason>` and exit 1.
3. Row → segment:
   - id `<mode>_<ref>` with `.` → `_` (e.g. `phan_xa_q2_a`); activity = mode label (`Hiểu`, `Nghe`, `Phản xạ`, `Nói`) — one section per mode (the source has no part headers).
   - `narrator` → speaker `coach_zh`, type `narration`, `zh-CN`, text/pinyin/translation from the row.
   - `wang_fang` / `chen_dong` → that speaker, type `dialogue`, `zh-CN`.
   - `coach_vi` → speaker `coach`, type `narration`, `vi-VN`, text = Tiếng Việt cell, no pinyin/translation.
   - every segment `pause_after_ms = LINE_PAUSE` (1000).
   - `gap` row → no segment; it sets the previous segment's `pause_after_ms`:
     in Phản xạ (answer gap) = `round(3000 + 1.5 × ZH_SECONDS_PER_CHAR × 1000 × hanzi_count(next row's text, the short answer `qN.a`)) + (1000 if the question contains any of 谁 哪 什么 几 还是 怎么 else 0)`, clamped to [3000, 7000] ms (user 2026-10-23: think time + answer length, more for wh-/choice questions); elsewhere (Nói repeat) = `clamp(round(1000 + 1.5 × ZH_SECONDS_PER_CHAR × 1000 × hanzi_count(prev text)), 2000, 8000)` ms.
4. Lesson per mode: meta.json fields + `format: "modes_v1"`, `variant: <mode>`, `version: 1`, `target_duration_minutes` = estimated minutes (zh chars × ZH rate + vi chars × VI rate from metrics.py + pauses), rounded, clamped to the schema range. Write `lessons/lesson_002_<mode>.json` (indent 2, `ensure_ascii=False`, trailing newline).
5. CLI `import-modes <ID>` prints ≤ 6 lines: one per mode `<mode>: <segments> segments, <gaps> gaps, ~<min> min`, then `Wrote 4 files`. `just import-modes ID` recipe.
6. `audit.py`: skip `format == "modes_v1"` files (they share `lesson_id` with no guided file); `mandarin-course audit` output for lesson 1 unchanged.
