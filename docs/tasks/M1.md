## Goal
A lesson declares a format. `linear_v1` (lesson 1, default when missing) stays exactly as today.
`modes_v1` (lesson 2) has four tracks `hieu`, `nghe`, `phan_xa`, `noi` and no `guided`.
This task changes only the contract and its readers; no importer, no publish logic.

## Do
Write the tests in Acceptance first.
1. **Python schema** (`lesson_schema.py`):
   - `Lesson.format: Literal["linear_v1", "modes_v1"] = "linear_v1"`.
   - `Lesson.variant` adds `"hieu" | "nghe" | "phan_xa" | "noi"`. Validator: `modes_v1` ⇒ variant is one of the four modes; `linear_v1` ⇒ variant is `None`, `guided` or `practice`.
   - `Speaker` adds `wang_fang`, `chen_dong`; both must be `zh-CN` (same rule as anna/li_ming).
   - `Lesson.voice_genders: dict[str, Literal["female", "male"]] = {}` — per-lesson role→gender override (lesson 2: `{"coach_zh": "female"}`). Keys must be Speaker values.
   - Existing `lessons/*.json` must still validate unchanged (no `format` key needed).
2. **Contract doc** (`content_package.md`), add a "Lesson formats" subsection:
   - catalog lesson entry gains `"format"`; absent = `linear_v1`.
   - `tracks` is an object keyed by track name. `linear_v1`: `guided` (required), `guided_zh`, `practice` (optional). `modes_v1`: `hieu`, `nghe`, `phan_xa`, `noi` (all four required), files `<mode>.mp3` + `timeline_<mode>.json`.
   - `reference.json` `tracks` uses the same keys as the catalog entry.
   - `modes_v1`: `items.json` is present with an empty item list; `characters.json` may omit characters that lack Vietnamese data (warning at publish).
   - Track display order + labels: `hieu` "Hiểu", `nghe` "Nghe", `phan_xa` "Phản xạ", `noi` "Nói".
3. **Kotlin shared** (`Models.kt`):
   - `CatalogLesson.format: String = "linear_v1"`.
   - `Tracks` becomes map-backed (JSON object of any keys; custom serializer or `Map<String, Track>` wrapper), keeping `forName(name)`, plus nullable `guided`, `guidedZh`, `practice` getters and `names: List<String>` in the format's display order (unknown keys last, sorted). Same for `ReferenceTracks` (`forName`, nullable `guided`/`practice`).
   - Parsing a catalog containing a `modes_v1` lesson must not throw.
4. **Facade** (`PlayerJs.kt` `tracksJson()`): `linear_v1` output unchanged; `modes_v1` → `[hieu "Hiểu", nghe "Nghe", phan_xa "Phản xạ", noi "Nói"]` (only tracks present).
5. **Android** (compiles against the new model; no new UI):
   - `LessonDownloadWorker` downloads every track in `tracks` (audio + timeline), not a fixed list.
   - The Android library hides `modes_v1` lessons (filter in one place, e.g. the repository/catalog mapping; comment `// modes_v1: Android support comes later`).
