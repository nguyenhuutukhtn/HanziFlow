## Severe (fix before regenerating audio)
1. **门口** explained as 门的旁边 → wrong (beside the door). Use 门口，意思是门前或入口的地方。
2. **Trần Đông's location contradicts itself**: narration says 陈东从八楼下来，在大厅找王芳, but drills confirm 陈东在八楼 / 陈东在大厅 / 陈东在几楼？→八楼 as if all at the same moment. Fix one state per character per moment across the whole lesson (all modes); drills must ask about a clearly named moment.
3. **王芳是不是在A座？ → 不是。王芳以为她在A座，她在B座。** adds 以为 information not established before, and 她 is hard to track by ear. Prefer 不是，王芳在B座。 Keep 以为 only where the story sets up the mistake.
4. **进去 explained as 我能进去** mixes action with ability. 进去 = go in; 进不去 = can't get in; example 我没有卡，进不去。
5. **怎么办 answer doesn't solve the problem**: 我没有卡，进不去，怎么办？→ 别急，你马上过来 doesn't address "no card". Use 别急，你等一下，我下楼接你。 Also 怎么办 glossed as "I don't know, I ask you" is wrong; = "what should I do?".

## Explanations to fix (Chinese)
- 等一下，意思是：你等我。→ 等一下，意思是：等一会儿。
- 马上，意思是：很快就来。→ 马上，意思是：很快，或者立刻。
- 接你，意思是：我去找你，我们一起走。→ 我去你那里，把你接过来。
- 开会，意思是大家一起说事情。→ 大家一起讨论事情。
- 不在，意思是：他没在大厅。→ don't teach 不在 via 没在 (confuses negation).
- 哪个，意思是：哪一个？→ explain: 用来问几个东西或地方中的哪一个。
- 什么 described as "answer with a name" → too broad; 什么 asks things/content, 谁 asks people.
- 楼下 ≠ 一楼 (楼下 is relative "downstairs"); don't present as synonyms.

## Context / clarity
- 门口在外面，大厅在里面 as a general definition is wrong; say 我从门口进去，里面是大厅。
- 我在楼下，门口这里 — understandable colloquially but awkward as a model sentence: 我在楼下的门口 / 我在楼下门口这里。
- 我旁边有一家咖啡店 then asking 王芳旁边有什么？ — audio-only learner needs to know who 我 is; set the scene (王芳 is next to the café) before asking.
- A座在B座对面 / 咖啡店在B座旁边 OK; ensure hanzi shown (座 vs 坐).
- Drills: fixed rule — 你在……？→ 我在……; 王芳在哪儿？→ 王芳在……; always clear who answers.
- 以为 needs a situation where reality differs from belief.
- 儿化 (哪儿) consistent.
- Many new words in one lesson (门口、大厅、楼下、哪儿、旁边、对面、看见、进去、等一下、别急、以为) — fewer words, more meaningful listen-answer turns (design note for later lessons).
